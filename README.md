# Notes-App

### A Google Keep-style notes app in React

![React](https://img.shields.io/badge/React-20232A?logo=react&logoColor=61DAFB) ![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?logo=javascript&logoColor=black) ![Material UI](https://img.shields.io/badge/Material%20UI-007FFF?logo=mui&logoColor=white)

Create, view, and delete notes in a card layout, with an expanding composer and Material UI icons.

```
notes-app/src/components
├── app.jsx          State: the list of notes
├── CreateArea.jsx   Expanding title + content composer
├── Note.jsx         A single note card with delete
├── Header.jsx
└── Footer.jsx
```

```bash
cd notes-app && npm install && npm start
```
